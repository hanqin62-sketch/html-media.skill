# 多场景、步骤视图与播放预览

[English](timeline.md) · [布局编辑基础](editor.zh-CN.md)

运行 `npm run demo:story`，打开终端打印的本地地址，体验两个场景的八秒示例。单页面仍使用 `npm run demo:editor`，不会因为信封移动、文字依次出现而被拆页。

## 用户操作

- 左侧列表显示场景名称、时间范围及节点布局概览；概览不是最终画面的缩小截图。单场景隐藏列表。
- **布局编辑**：显示作者定义的完整布局，支持拖动、分组、撤销等。恢复初稿和撤销历史按场景保存，切换场景不会丢失编辑。
- **布局步骤**：只显示该步骤声明的节点，以及两端都可见的连线。适合依次展示或占用相同位置的内容；选择“完整布局”会显示所有节点。完整布局中的互斥内容可能重叠，切换步骤单独调整。分组关系仍然有效，移动组时可能同时移动当前步骤隐藏的组成员。
- **播放预览**：播放、暂停、回到开头、拖动进度。进度覆盖整段视频，到场景边界自动切换；播放时锁定布局操作。回到布局模式后继续编辑，不把暂停时的动画位移误存成基础布局。
- 标签页隐藏时暂停。进度按导出帧率采样，到末尾停在最后一个可导出帧；性能较慢时预览可能跳过帧，但导出仍逐帧计算。
- 保存会保留全部场景的布局。**PNG/JPEG 导出当前播放时间对应的真实画面**，点击导出时切到播放预览；布局/步骤视图是编辑辅助视图。**MP4 始终导出完整时间线**，不会只导出当前场景。

本版不提供关键帧、场景重排、自动分场景或转场编辑；场景顺序和时长由配置声明。需要纠正场景划分时修改配置和模板；不要把单场景的每个动作变成一页。

## 配置

在已有配置中使用 `timeline` 替代 `layout`，两者不能同时存在。所有场景使用同一 HTML 文件、相同画布尺寸，节点和根容器选择器在整个项目中互不复用。

```json
{
  "version": 1,
  "template": "story.html",
  "text": [
    { "id": "title", "selector": "#result-title", "sceneId": "result", "text": "查询结果", "visibleFrom": 0.5 }
  ],
  "timeline": {
    "version": 1,
    "scenes": [
      {
        "id": "result", "label": "返回结果", "duration": 4, "editTime": 2,
        "steps": [
          { "id": "answer", "label": "收到答案", "time": 1, "nodes": ["card"] }
        ],
        "layout": {
          "version": 1, "root": "#result", "width": 1000, "height": 560,
          "nodes": [{ "id": "card", "selector": "#card", "label": "答案", "x": 100, "y": 180, "width": 300, "height": 180 }],
          "connections": []
        }
      }
    ]
  }
}
```

完整示例：[story.json](../assets/examples/story.json) / [story.html](../assets/templates/story.html)。

- 最多 50 个场景，合计不超过一小时；每场景至少 0.01 秒。`editTime` 和步骤的 `time` 是场景内的局部时间，必须小于该场景时长。
- `editTime` 是完整布局对应的播放参考时间。步骤的 `nodes` 是允许显示的节点 id 列表，可为空。步骤最多 100 项，节点定义沿用布局格式。
- 配置的每条 `text` 都必须有有效 `sceneId`。文字 `visibleFrom/visibleUntil` 按场景内时间填写，读入时自动换算成全局检查窗口；默认覆盖整个场景。进入/退出动画需要声明真实可见区间。
- 文字原文仍在所有帧核对，基础可见性与字体采样只在所属时间窗口进行。不要在不同场景共用一个不断改字的 DOM 节点，应使用独立元素。
- 画布尺寸和视频总时长自动取自时间线。显式 `--duration` 必须等于所有场景时长之和；静帧 `--time` 为全局时间且必须小于总时长。旧的单页面参数保持兼容。

## 模板接口

每个场景根容器直接放在 body 下，结构约定沿用布局编辑器。运行时控制根容器的可见性、透明度、交互与无障碍隐藏状态，切换采用硬切。

```js
window.renderAt = (localSeconds, { sceneId, globalTime, mode }) => {
  // 每次从时间重算当前场景的完整状态，不依赖上一次调用。
  // 使用当前场景的 window.htmlMediaLayout.pointOnConnection(...) 计算运动路径。
};

window.renderLayout = ({ sceneId, stepId, localTime }) => {
  // 为编辑显示元素到位后的状态：恢复子元素透明度/位置，隐藏运动信封等临时元素。
  // 不改写批准文案；不修改节点包装层的基础坐标。
};
```

`renderAt` 是导出与播放共用的接口。`renderLayout` 是多场景编辑器必需的完整布局接口，不会用于视频导出。后者调用后，运行时再按步骤控制节点和连线的显隐。两种函数都必须可重复调用、可反向跳转；不能依赖累积计时、随机数或上一次场景状态。

动画建议通过这些时间函数控制节点子元素，包装层不要使用 `display:none`、尺寸动画或变换，以免破坏布局坐标。CSS/Web Animations 按当前场景局部时间暂停采样；完整布局钩子需要自行处理仍影响布局视图的子元素动画，不会自动重建任意动画源码。

`window.htmlMediaTimeline.state()` 可观察当前 sceneId、globalTime、localTime、mode、stepId；`locate(seconds)` 提供场景定位。`window.htmlMediaLayout` 始终指向当前场景。场景累计边界按纳秒精度归一，避免 0.1 + 0.2 一类浮点误差造成多采一帧。

仍需查看导出视频的开头、边界前后和结尾。多场景能力不包含音轨、实拍视频分解或自动检测遮挡。
