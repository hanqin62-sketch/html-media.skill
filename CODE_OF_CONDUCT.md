# Community conduct / 社区行为准则

We want people with different languages, backgrounds, and levels of experience to be able to work together.

我们希望不同语言、背景和经验水平的参与者都能一起协作。

- Be respectful and specific. Discuss the work, not a person's worth. 保持尊重，针对具体工作讨论。
- Welcome questions, constructive disagreement, and corrections. 欢迎提问、建设性分歧和纠正。
- Do not harass, threaten, discriminate, expose private information, or spam. 不骚扰、威胁、歧视、泄露隐私或发布垃圾信息。
- Respect asset licenses and other contributors' credit. 尊重素材许可和贡献者署名。

These expectations apply in issues, pull requests, and other project spaces. Maintainers may ask for changes, remove inappropriate content, lock discussions, or restrict participation when needed, considering context and proportionality.

这些要求适用于 Issue、PR 和项目交流空间。维护者可根据情节要求修改、移除不当内容、锁定讨论或限制参与，并尽量采取与问题程度相称的措施。

Use GitHub's reporting tools for abuse or contact a maintainer through a contact channel they publish. Do not post private evidence publicly. This project does not currently provide a dedicated confidential moderation inbox.

遇到滥用行为可使用 GitHub 的举报功能，或通过维护者公开提供的联系方式联系。不要公开发布隐私证据；项目目前没有专用的保密投诉邮箱。
